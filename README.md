# Pensa.club - A Platform for Connecting Elderly People

## Project Overview

Pensa.club is a platform designed to make it easier for elderly people to use the internet and connect with others in their region. The main features of the platform include an interactive map, based on OpenStreetMap, where users appear on the map after registration. This aims to facilitate easier connections between users who are located close to each other. Additionally, the platform provides the ability to create and view listings.

### Key Features
- **Interactive Map**: Users can register a profile and be visualized on the map using OpenStreetMap.
- **Listings**: Creation and viewing of listings, which are moderated by an administrator.

### User Roles
- **Guest**: Has no permissions to view or create listings.
- **User**: Can add listings and view approved ones.
- **Administrator**: Can approve and delete listings, as well as change user roles.
- **Admin Dashboard with Statistics**: An administrator can access a comprehensive statistics dashboard, created using Recharts, to visualize key metrics such as user growth, active vs. inactive users, and ad performance.

## Technologies

The project was implemented using the following technologies:
- **Front-end**: React.js
- **Back-end**: Node.js with Express
- **ORM and Migrations**: Sequelize
- **Database**: PostgreSQL
- **Interactive Map**: OpenStreetMap
- **Authentication and Data Storage**: Firebase
- **Hosting**: Render.com
- **Domain**: [pensa.club](https://pensa.club)

## Methodology and Organization

The project was developed over 3 months, involving a team of 6 people (3 Front-end, 2 Back-end, 1 Designer). We followed Agile methodologies with two- to three-week sprints.

- **Meetings**: We held over 30 daily meetings (Monday-Wednesday-Friday), as well as two demo meetings with the client. Additionally, the client received regular weekly updates on design progress and requested changes.
- **Jira**: We managed our tasks through Jira, with nearly 90 tickets created and completed during the period, divided into 5 sprints.
- **GitHub**: The work on the project resulted in over 250 pull requests on GitHub.
- **Training**: The students involved in the project gained essential skills in working on a real-world project and modern technologies such as React.js, Node.js/Express, Sequelize, PostgreSQL, and working with OpenStreetMap and Firebase. They also acquired solid foundations in Git (committing, creating PRs, resolving conflicts) and experience working with pre-made designs in Figma.
