=== ЗАДАЧА: Admin Site Settings Page ===
Дата: 2026-02-22
Приоритет: Висок

== ОПИСАНИЕ ==
Да се създаде нова страница "Настройки на сайта" (Site Settings), достъпна САМО за админи.
От тази страница админите ще могат да включват/изключват глобални функции на сайта.
За начало: управление на два съществуващи компонента — GlobalSnowfall и ChristmasGreetingModal.
Страницата трябва да е проектирана като layout за много бъдещи настройки (extensible).

== КЪДЕ СЕ НАМИРА ==
- В Profile компонента има админска част — там да се добави линк към новата страница.
- Страницата ещ се отваря самостоятелно няма да е в Profile
- Нов route:/site-settings (или подобен, защитен само за админи) в App.jsx
- Достъп: САМО потребители с админ роля.

== КАКВО ТРЯБВА ДА СЕ НАПРАВИ ==

1. BACKEND (Server):
   - Нов endpoint за Site Settings (CRUD):
     * GET /api/admin/site-settings — връща текущите настройки
     * PUT /api/admin/site-settings — обновява настройки
   - Настройките да се пазят в PostgreSQL (нова таблица site_settings или key-value подход)
   - Middleware проверка за админ роля на всеки endpoint
   - Начални настройки:
     * snowfall_enabled: boolean (default: false)
     * christmas_greeting_enabled: boolean (default: false)
   - Таблицата да е проектирана за лесно добавяне на нови настройки в бъдеще

2. FRONTEND — Нова страница SiteSettings:
   - Път: client/src/components/SiteSettings/SiteSettings.jsx + siteSettings.css
   - Ако компонентът стане твърде дълъг — разбий на подкомпоненти:
     * client/src/components/SiteSettings/SettingsSection/SettingsSection.jsx + settingsSection.css
     * client/src/components/SiteSettings/SettingsToggle/SettingsToggle.jsx + settingsToggle.css
   - Ако трябват custom hooks:
     * client/src/hooks/useSiteSettings.js
   - Layout: предвиден за много секции с настройки, не само за тези две
   - Всяка настройка: Toggle бутон + заглавие + описание + статус индикатор

3. ДИЗАЙН:
   - Модерен, чист дизайн
   - Цветова гама: РАЗЛИЧНА от Academy темата (НЕ оранжево/синьо)
     * Предложение: emerald/teal (#10b981, #14b8a6) + slate (#1e293b, #334155) + violet акценти (#8b5cf6)
     * Или друга модерна комбинация — но НЕ Academy цветовете
   - Тъмна и светла тема поддръжка (с [data-theme="light"] подход)
   - Toggle бутоните да са стилни, анимирани (ON/OFF с плавен slide)
   - Всяка секция с настройки да е в card с леки сенки и hover ефект
   - Success/Error toast при запазване
   - Loading state при fetch

4. PROFILE КОМПОНЕНТ:
   - В админската част на Profile да се добави линк/бутон "Настройки на сайта"
   - Линкът да води към /admin/site-settings
   - Да е видим САМО за админи

5. ИНТЕГРАЦИЯ:
   - GlobalSnowfall и ChristmasGreetingModal да четат състоянието от backend
   - При промяна на toggle → PUT заявка → компонентите реагират в реално време
   - Може да се ползва Context или директен fetch при зареждане на App

== ПРАВИЛА ЗА РАБОТА ==

СТРУКТУРА НА ФАЙЛОВЕТЕ:
- Компоненти: client/src/components/[ComponentName]/[ComponentName].jsx + [componentName].css
- Подкомпоненти: client/src/components/[ParentComponent]/[SubComponent]/[SubComponent].jsx + [subComponent].css
- Hooks: client/src/hooks/[hookName].js
- Ако кодът на компонент надвишава ~300 реда — задължително се разбива на подкомпоненти

CSS ПРАВИЛА:
- Всеки CSS файл използва УНИКАЛЕН prefix за класовете (примерно ss- за SiteSettings, st- за SettingsToggle)
- НЕ се използват глобални класове
- Responsive: монитори, лаптопи, таблети, телефони (малки + големи)

i18n:
- Всички текстове минават през i18n
- i18n обект = име на компонента (siteSettings.title, siteSettings.snowfallLabel и т.н.)
- Преводи: bg, en, de
Други:
- Никога да се комитва мърджва или пушва към гитхъб без мое разрешение 


BACKEND ПРАВИЛА:
- Controller в server/controllers/
- Routes в server/routes/
- Middleware за auth + admin check
- Валидация на входните данни

== ФАЙЛОВЕ ЗА РАЗГЛЕЖДАНЕ ПРЕДИ РАБОТА ==

- GlobalSnowfall компонента — къде е, как работи
- ChristmasGreetingModal компонента — къде е, как работи
- server/routes/ — как са структурирани другите routes
- server/controllers/ — конвенции за controllers
- Всички останли от сървъра

- Натиска → отваря се красива страница с карти за настройки
