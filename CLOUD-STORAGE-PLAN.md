# Cloud Storage & File Manager — План за Фондация ПЕНСА

---

## ЗАЩО ГО ПРАВИМ?

В момента файловете на фондацията се пращат по имейл, губят се, няма централно място. Семинарните файлове се качват с ID номера които никой не разбира. Трябва ни:

- **Едно място** за всички документи на фондацията — достъпно от платформата И от Google Cloud Console
- **Автоматична организация** — семинарните файлове сами се подреждат по папки
- **Споделяне** без имейли — линк или директно в платформата
- **Ментори/админи/модератори** да качват от телефон или компютър

---

## ФАЗА 1: Семинари — подреждане на файловете
**Статус: ТЕКУЩА**

### Какво правим?
Файловете от семинарите вече се качват в Google Cloud Storage (Firebase bucket), но пътищата са грозни — `seminars/photos/12/1712345678_file.jpg`. Никой не може да ги намери в Cloud Console.

### Какво ще се промени?
Вместо:
```
seminar-attendance-lists/12/1712345_file.pdf
seminars/photos/12/1712345_snapshot.jpg
seminars/presentations/12/1712345_slides.pptx
```

Ще стане:
```
seminars/semian-test/lists/attendees-list.pdf
seminars/semian-test/photos/snapshot.jpg
seminars/semian-test/presentations/slides.pptx
seminars/workshop-paroli/photos/group-photo.jpg
```

### Как работи?
1. Ментор/админ качва файл от платформата (библиотека или страницата за записвания)
2. Файлът автоматично отива в правилната папка по име на семинара
3. Ако папката не съществува — създава се автоматично
4. Видеата НЕ се качват тук — те си остават в YouTube

### Как да тествам?
1. Отвори платформата → Семинари → Библиотека → избери семинар
2. Качи снимка, презентация или списък
3. Отвори Google Cloud Console → Cloud Storage → bucket `pensaclub-909e0.appspot.com`
4. Навигирай до `seminars/` → трябва да видиш папка с името на семинара → вътре подпапки `photos/`, `presentations/`, `lists/`
5. Файлът трябва да е там с четимо име

## ФАЗА 2: File Manager в Settings
**Статус: СЛЕДВАЩА**

### Какво правим?
Нов раздел в админ Settings — файлов мениджър (като мини Google Drive), директно свързан с Cloud Storage.

### Цел
Всеки с админ достъп може от платформата да:
- Разглежда ВСИЧКИ файлове и папки в хранилището
- Създава нови папки (напр. "Проект ReAction / Отчети 2026")
- Качва файлове с drag & drop
- Преименува, премества, изтрива
- Сваля файлове или цели папки (ZIP)
- Вижда preview на снимки и PDF

### Как работи?
1. Админ отваря Settings → таб "Хранилище"
2. Вижда дървовидна структура: `pensa-foundation/`, `seminars/`, `courses/`
3. Кликва на папка → вижда файловете вътре (grid или list view)
4. Drag & drop файл → качва се в текущата папка
5. Десен бутон на файл → Download, Rename, Move, Delete
6. Бутон "Нова папка" → създава подпапка
7. Checkbox-ове на файлове → "Свали избраните (ZIP)" или "Изтрий избраните"

### Permissions (кой какво вижда)
- **Админ:** вижда и управлява ВСИЧКО
- **Модератор:** качва и разглежда, не може да трие чужди файлове
- **Ментор:** вижда САМО `seminars/{неговите-семинари}/`

### Как да тествам?
1. Отвори Settings → Хранилище
2. Навигирай до `seminars/` → трябва да видиш всички семинари с папки
3. Създай нова папка `test-folder/`
4. Качи файл в нея
5. Отвори Google Cloud Console → провери че файлът и папката са там
6. Изтрий файла от платформата → провери че е изтрит и от Cloud Console
7. Качи файл директно от Cloud Console → провери че се вижда в платформата (Фаза 3)

## ФАЗА 3: Автоматична синхронизация
**Статус: СРЕДНОСРОЧНА**

### Какво правим?
Когато някой качи файл директно в Google Cloud Console (без да минава през платформата), той автоматично да се покаже в платформата.

### Как работи?
1. Админ качва файл в Cloud Console → `seminars/semian-test/photos/new-photo.jpg`
2. Google Cloud Function се задейства автоматично (trigger при upload)
3. Cloud Function разпознава пътя: "Aha, това е снимка за семинар semian-test"
4. Създава запис в базата данни (`seminar_media` таблицата)
5. Следващия път когато отвориш библиотеката → снимката е там

### Обратно:
1. Ако изтриеш файл от Cloud Console → Cloud Function маркира записа в DB като изтрит
2. Cron job (всяка нощ) проверява за несъответствия и почиства

### Как да тествам?
1. Качи снимка директно в Cloud Console → `seminars/semian-test/photos/test-sync.jpg`
2. Отвори платформата → Библиотека → Semian test → Снимки
3. Снимката трябва да е там (може с 1-2 минути забавяне)
4. Изтрий я от платформата → провери че е изтрита и от Cloud Console

## ФАЗА 4: Организация на фондацията
**Статус: СРЕДНОСРОЧНА**

### Какво правим?
Създаваме структура от папки за цялата фондация — документи, проекти, комуникации, срещи.

### Структура:
```
pensa-foundation/
  administration/              ← Договори, финансови отчети, HR
    contracts/
    financial-reports/
    hr/
  projects/                    ← Всеки проект в своя папка
    project-reaction/
      documents/
      reports/
      media/
    digibridge-academy/
      documents/
      reports/
    erasmus-plus/
  communications/              ← Брандинг, шаблони, прес материали
    branding/
      logos/
      templates/
    press-releases/
  meetings/                    ← Протоколи и материали от срещи
    2026/
      01-january/
      02-february/
seminars/                      ← Автоматично от Фаза 1
courses/                       ← За бъдещо ползване
```

### Как работи?
1. При първо стартиране — автоматично създава основните папки
2. В File Manager → Quick links: "Проекти", "Администрация", "Семинари"
3. При нов проект → бутон "Създай проект" → автоматично генерира папките (documents/, reports/, media/)

### Как да тествам?
1. Отвори Settings → Хранилище
2. Кликни "Инициализирай структура" (еднократно)
3. Провери в Cloud Console — всички папки трябва да са създадени
4. Качи документ в `pensa-foundation/projects/project-reaction/reports/`
5. Провери от платформата и от Cloud Console

## ФАЗА 5: Споделяне без имейли
**Статус: ДЪЛГОСРОЧНА**

### Какво правим?
Вместо да пращаме файлове по имейл — споделяме линк или директно в платформата.

### Как работи?

**Вариант 1 — Публичен линк:**
1. Десен бутон на файл → "Генерирай линк"
2. Избираш: валидност (1 ден / 7 дни / 30 дни / безсрочно), парола (optional)
3. Копираш линка → пращаш по имейл/чат/Viber
4. Получателят отваря линка → сваля файла (дори без акаунт в платформата)

**Вариант 2 — Вътрешно споделяне:**
1. Десен бутон на файл → "Сподели с..."
2. Избираш потребител от платформата
3. Потребителят получава нотификация: "Боби сподели с теб файл: отчет-q1.pdf"
4. Кликва → отваря файла
5. В Settings → "Споделени с мен" — вижда всички споделени файлове

**Вариант 3 — В имейл модала:**
1. Пишеш имейл от платформата (напр. на участник в семинар)
2. Бутон "Прикачи от хранилището"
3. Отваря File Manager → избираш файл → прикачва линк в имейла

### Как да тествам?
1. Генерирай публичен линк → отвори в инкогнито режим → трябва да сваля файла
2. Сподели файл с друг потребител → провери дали получава нотификация
3. Сподели файл с парола → опитай без парола (трябва да откаже) → опитай с парола (трябва да работи)
4. Генерирай линк с валидност 1 ден → след 1 ден линкът не трябва да работи

## ФАЗА 6: Mobile & Разширени функции
**Статус: ДЪЛГОСРОЧНА**

### Какво правим?
Оптимизация за телефон + търсене + analytics.

### Как работи?

**Mobile:**
- Ментор на семинар → отваря телефона → снима → "Качи в хранилището" → избира семинар → готово
- Responsive File Manager — работи на телефон и таблет
- Camera capture бутон при upload

**Търсене:**
- Поле за търсене в File Manager
- Търси по име на файл, по папка, по дата
- Филтър по тип: снимки / документи / презентации / всички

**Analytics:**
- Dashboard: колко storage е използван, топ папки по размер
- Activity log: кой какво е качил/изтрил и кога
- Последно качени файлове

### Как да тествам?
1. Отвори File Manager на телефон → трябва да е удобен за ползване
2. Снимай нещо → качи директно → провери в Cloud Console
3. Търси файл по име → трябва да го намери
4. Отвори Analytics → провери статистиките

## ВАЖНИ БЕЛЕЖКИ

### Firebase Storage = Google Cloud Storage
Един и същ bucket. Не е нужна миграция. Всичко което качваме от платформата е видимо и в Cloud Console.

### Видеата остават в YouTube
Видеата НЕ се качват в Cloud Storage — те си остават в YouTube канала на Pensa (unlisted). Само URL-ът се записва в базата.

### Кой има достъп до Cloud Console?
Всеки с достъп до pensa.club@gmail.com може да влезе в Google Cloud Console и да вижда/качва файлове директно. File Manager-ът в платформата е за удобство — не замества Cloud Console, а го допълва.

### Лимити
- Firebase Blaze plan: 5GB безплатно, после $0.026/GB месечно
- Максимален размер на файл: 500MB (за uploads от платформата)
- Без лимит на брой файлове
